# Оценка кредитоспособности

Из папки `credit_web` выполните:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn main:app
```

Откройте `http://127.0.0.1:8000`. Выберите заемщика и нажмите «Показать оценку». Исходные поля доступны в разделе «Все данные заемщика». Раскройте любую группу баллов, чтобы увидеть основания.

FastAPI и Protégé используют `../credit_ontology.owl` со встроенными правилами SWRL. Чтобы добавить заемщика, заполните анкету и нажмите «Добавить и рассчитать». Запись сохраняется в `borrowers.sqlite3`. Кнопка «Скачать онтологию с анкетами и оценками» выгружает `credit_ontology_export.owl` со всеми анкетами, баллами, решениями и встроенными правилами.

Оценка начинается с 0. Каждый фактор прибавляет или вычитает баллы. Отрицательные результаты сохраняются. Порог выдачи составляет +25 баллов. Годовая ставка по умолчанию составляет 24%, платеж аннуитетный, комиссий нет.

Возраст сопоставляется с заявленным стажем. Остальные поля анкеты влияют через проверки бюджета домохозяйства, связи квалификации с доходом, расходов по месту проживания и обоснованности суммы кредита. Подтвержденный критерий дает +2, выявленное несоответствие дает −2, отсутствие проверки дает 0.

Правила начисления и порядок запуска SWRL, SQWRL и SPARQL описаны в `../credit_score_protege.txt`.
